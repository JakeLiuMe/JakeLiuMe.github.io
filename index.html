When the backtest lies: an options research post-mortem

Jan – Apr 2026 · retired

A research pipeline on 233M+ intraday option quotes across 36 underlyings (2018–2026): strategy discovery, walk-forward testing (train 2018–22, test 2023–25), and Monte Carlo simulation with market-impact costs.

  • The backtests looked excellent. Rerunning the entire discovery process on shuffled data "found" strategies that were just as good (permutation p = 0.995), so the edge came from the search, not the market.
  • A paper-trading run through the Tradier brokerage API confirmed it. I shut the strategy down; no real money was ever at risk.
  • What I apply everywhere now: test the search process against noise, count every variant tried, and put hard risk limits in code before the first live dollar.
